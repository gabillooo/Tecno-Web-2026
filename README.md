# PermisosApp - Administración y Ciudadanía

Aplicación demostrativa para la administración y consulta ciudadana de Permisos, Licencias y Patentes. Funciona con datos locales.

## Inicio rápido

```bash
npm install
npm start
```

## Conclusión

PermisosApp es una aplicación web demostrativa para la gestión administrativa y la consulta ciudadana de permisos municipales. El perfil administrador puede revisar solicitudes, consultar el catálogo y ver estadísticas. El perfil ciudadano puede consultar las patentes emitidas y las solicitudes asociadas a su cuenta.

En su estado actual, la aplicación funciona como prototipo académico con datos locales y credenciales de demostración; no tiene una conexión a un backend de producción. Permite recorrer la consulta de patentes ciudadanas y un flujo administrativo básico, y muestra cómo integrar componentes, servicios y control de acceso en Angular.
